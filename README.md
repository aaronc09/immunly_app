# Immunly

**Immunly** is an interactive educational application designed to make learning immunology more accessible and engaging.

The app organizes immunology concepts into structured learning modules and provides tools to help users learn, review, and track their progress.

## Features

* 📚 Structured immunology learning modules
* 📝 Interactive lessons and quizzes
* 📊 Progress tracking
* 📖 Immunology glossary
* 🤖 ImmunoBot for interactive learning
* 📱 Support for web and mobile platforms

## Built With

Immunly is built using:

* React Native
* Expo
* TypeScript
* React Navigation
* React Native Web

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aaronc09/immunly.git
cd immunly
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

Start the Expo development server:

```bash
npm start
```

Or run the web version directly:

```bash
npm run web
```

## Project Structure

```text
src/
├── screens/       # Main application screens
├── data/          # Application data and progress management
├── theme/         # Colors and visual styling
└── types/         # TypeScript definitions
```

The application includes separate screens for the home page, learning modules, lessons, quizzes, progress tracking, glossary, and ImmunoBot.

## Purpose

Immunology can be challenging because it involves many interacting cell types, signaling pathways, receptors, and immune responses. Immunly was created to provide a more approachable way to learn and review these concepts through organized lessons and interactive tools.

## Disclaimer

Immunly is intended for educational purposes only. It is not intended to provide medical advice, diagnosis, or treatment.
